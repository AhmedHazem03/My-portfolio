An interactive portfolio for **Ahmed Hazem**, a Full-Stack Software Engineer building production business systems, dashboards, e-commerce platforms, and client portals.

The experience uses an IDE-inspired interface to present professional work, technical expertise, project case studies, and career history in a more memorable format than a static landing page.

## Live Portfolio

[ahmed-portfolio-coral.vercel.app](https://ahmed-portfolio-coral.vercel.app/)

## What it showcases

- **Production systems:** DEX Agency OS, Mahalk operations and delivery workflows, Jada Perfumes, and Elite International Schools.
- **Full-stack delivery:** Next.js, TypeScript, ASP.NET Core foundations, Supabase/PostgreSQL, Flutter, and production integrations.
- **Business outcomes:** workflows, approvals, client portals, treasury and reporting, e-commerce journeys, real-time operations, and mobile delivery flows.
- **Interactive interface:** VS Code-inspired navigation, searchable projects, responsive layouts, 3D network visual, career timeline, and skill explorer.

## Tech stack

- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **3D:** React Three Fiber, Drei, Three.js
- **Icons:** Lucide React

## Project structure

```text
├── components/
│   ├── Hero3D.tsx       # Animated network background scene
│   └── ProjectCard.tsx  # Interactive project presentation
├── App.tsx              # IDE-inspired application layout and views
├── constants.tsx        # Portfolio content: bio, work, projects, skills, services
├── types.ts             # Shared TypeScript types
├── index.css            # Global styling and UI utilities
└── index.html           # Metadata and application entry point
```

## Local development

```bash
# Clone
git clone https://github.com/AhmedHazem03/My-portfolio.git
cd My-portfolio

# Install dependencies
npm install

# Run locally
npm run dev

# Production build
npm run build
```
